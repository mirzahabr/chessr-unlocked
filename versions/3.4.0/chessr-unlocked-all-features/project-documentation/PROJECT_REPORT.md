# Project Report: Chessr.io v3.4.0

## Учебная цель

Практикант документирует архитектуру Manifest V3, взаимодействие background
service worker и content scripts, локальные chess engines и модель угроз.

## Методика и границы

Работа ведётся офлайн на законно полученных файлах. Не выполняются запросы к
чужим аккаунтам, не обходятся лицензии или подписки, не подменяются ответы
серверов и не автоматизируются партии. Неизвестные backend-зависимости помечены
как непроверенные.

## Результат

Составлены карта компонентов, перечень разрешений, журнал наблюдений и список
воспроизводимых проверок. Reference build сохраняется отдельно, чтобы каждое
изменение можно было объяснить и проверить.

## Дальнейшая работа

Добавить тестовый стенд без внешних сервисов, проверить лицензии поставляемых
движков и подготовить ответственное раскрытие потенциальных проблем владельцу.
